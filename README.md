# 英語寵物探險島 · 第三關

適合臺灣國小五、六年級的英語寵物養成遊戲。無需帳號、安裝或後端，使用繁體中文介面與第三關的 21 個英文句型。

**[點這裡開始遊戲](https://htmlpreview.github.io/?https://github.com/imacipadtw-lang/stage3chat/blob/c295fae76fb5fc77b03a3c6ba279fa595cb8cc49/play.html)**

完整程式已上傳 GitHub。此網址使用 HTMLPreview 直接開啟 GitHub 上的固定版本，不需要登入。`play.html` 內含遊戲程式、教材、樣式與寵物圖片，並保留教師設定。GitHub Pages 尚未啟用：目前平台授權沒有 Pages 寫入權限；這不影響上方遊戲網址的使用。

## 學生使用

開啟網址後跟著圖像教學開始。聽英文選物品、點選單字組句子、閱讀情境選出英文回答，完成今日任務。答錯可以再試，並安排後續複習；沒有倒數計時。

同一瀏覽器會保存進度，回來時可以繼續。私人瀏覽、清除網站資料或改用其他裝置不會保留原先進度；儲存受限時遊戲會提示，當次練習仍可進行。

英文優先使用教師設定的錄音，否則使用裝置的英文語音。點選播放按鈕可重播，並調整語速。不同裝置提供的語音可能不同；語音不可用時仍可閱讀英文完成練習。

## 教師使用

首頁的教師設定可調整題數、更換教材、檢視輸入格式、重設進度及匯出學生版。教材以英文、中文意思與圖片/物品對應為一組；可貼入兩欄 Markdown 表格，或依介面中的 JSON 範例設定情境、圖示與錄音。

請先核對教材的文法、拼字、翻譯和圖片對應，再交付給孩子。教材範例即本次提供的完整 21 句。`My throat hurts.` 與 `My throat is sore.` 都表示喉嚨痛；遊戲避免將兩者設為同一語意選擇題中互相競爭的答案。

學生版為可下載的 HTML 檔案，保留選定教材與寵物圖像，不提供教師編輯入口。可直接在支援 JavaScript 的瀏覽器開啟，或放到自己的靜態網站。外部錄音需要網路；裝置語音是否離線可用取決於系統。

## 本機開發

使用既有 checkout，無需另外建立 Git worktree，也沒有套件安裝步驟。

```bash
cd /workspace/stage3chat
python3 -m http.server 8765 --bind 127.0.0.1
```

在本機瀏覽器開啟服務，檢查首頁、完成任務及教師設定。若另外啟用 GitHub Pages，可選擇 `main` 分支根目錄；`.nojekyll` 讓所有靜態檔案直接提供服務。

修改遊戲來源後，執行 `python3 build-preview.py` 重新產生完整的 `play.html`。公開預覽保留教師設定；教師匯出學生版時會讀取同目錄的來源檔，因此需有網路或本機靜態服務。匯出的學生 HTML 可獨立離線開啟。

## 檔案

- `index.html`：網站入口。
- `play.html`：內含程式、樣式、教材與圖片的完整預覽入口。
- `build-preview.py`：從來源檔重建完整預覽，無需安裝套件。
- `styles.css`：iPad 橫式優先、觸控與直式相容版面。
- `curriculum.js`：21 句教材與圖像、情境對應。
- `app.js`：題目、寵物、進度、教師設定、語音與匯出。
- `assets/pet.webp`：原創 3D 潮玩寵物，透明背景，約 169 KB。

沒有分析追蹤、廣告或收集學生個人資料的功能。學習進度保存在使用者自己的瀏覽器。
